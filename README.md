
# Foundation

A reusable AI Engineering System for building software with AI agents.

## Vision

Foundation provides a structured engineering environment where AI agents can collaborate to plan, implement, test, review, and maintain software projects.

## Core Components

- Engineering Rules
- Reusable Agent Skills
- Specialist Agents
- Development Workflows
- Project Templates
- Quality Gates
- Automation Scripts

## Development Roadmap

### Stage 1 — Foundation
Establish repository structure, engineering standards, and initial reusable skills.

### Stage 2 — Agent Organization
Introduce specialist agents and controlled delegation.

### Stage 3 — Automation
Integrate tools, hooks, testing, and automated quality checks.

### Stage 4 — Autonomous Engineering
Introduce bounded autonomous development, recovery, and reporting workflows.

## Guiding Principle

Understand → Plan → Implement → Verify → Review → Report
