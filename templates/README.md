
# Foundation Templates

## Purpose
This directory contains reusable documentation templates for software engineering projects developed using Foundation.

Templates provide consistent structures for project discovery, architecture design, implementation planning, feature specifications, bug reports, and other engineering activities.

## Usage

1. Identify the document needed for the current task.
2. Copy the relevant template into the target project's documentation directory.
3. Rename it appropriately.
4. Replace all placeholders with project-specific information.
5. Keep the document updated as the project evolves.

## Available Templates

| Template | Purpose |
|---|---|
| `project-discovery-template.md` | Capture project requirements and objectives |
| `architecture-template.md` | Document system architecture and technical decisions |
| `implementation-plan-template.md` | Break project development into phases and tasks |

## Guidelines

- Do not leave unexplained placeholders in completed documents.
- Avoid inventing requirements or technical decisions.
- Keep documentation consistent with the actual implementation.
- Record important architectural decisions.
- Update `docs/Project_Notes.md` whenever meaningful project changes occur.

## Future Templates

Additional templates will be added as Foundation evolves.
